# Allay Therapeutics

> Clinical-stage biopharmaceutical company (San Jose, CA and Singapore) developing ultra-sustained,
> non-opioid analgesic products for post-surgical pain management. Its platform is a tunable
> drug-biopolymer architecture that pairs validated non-opioid analgesics with dissolvable
> biopolymers to release relief at a targeted surgical site over weeks rather than days. Lead
> candidate ATX-101 is a bupivacaine-based implant for total knee replacement, holding FDA
> Breakthrough Therapy Designation and in a pivotal Phase 2b registration trial.

Allay Therapeutics is a therapeutics developer, not a software company. It runs **no developer
program**: no developer portal, no API documentation, no SDKs, no CLI, no webhooks, no MCP server,
no A2A agent card, no status page and no sandbox. The only machine-readable interface reachable
without credentials is the WordPress REST content API behind the marketing site, catalogued below.

This file was generated by API Evangelist from the public surface at www.allaytx.com on 2026-08-06.
